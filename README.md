# Сапёр

Веб-игра «Сапёр» на HTML, CSS и JavaScript. Работает на компьютере, планшете и телефоне, устанавливается как мобильное приложение.

**Играть:** https://nabolgod.github.io/Sapper/

**Скачать для Android (APK):** https://github.com/Nabolgod/sapper/releases/latest

## Мобильное приложение

| Телефон | Как установить |
| --- | --- |
| Android | Скачать APK из раздела Releases и открыть его. Либо открыть игру в Chrome → меню → «Установить приложение» |
| iPhone | Открыть игру в Safari → «Поделиться» → «На экран «Домой»» |

После установки игра открывается с иконки на рабочем столе, на весь экран и работает без интернета.

Технология: Progressive Web App (манифест + service worker), Android-пакет собран в PWABuilder.

## Правила

Под клетками спрятаны мины. Чтобы победить, откройте все клетки без мин.

- Цифра в клетке показывает, сколько мин в соседних клетках (соседей до 8).
- Если рядом нет мин, соседние клетки открываются сами.
- Первый ход всегда безопасный.
- Клетку, под которой точно мина, можно отметить флажком.

## Управление

| Действие | Компьютер | Телефон и планшет |
| --- | --- | --- |
| Открыть клетку | Левый клик | Касание |
| Поставить или снять флажок | Правый клик | Долгое нажатие |
| Новая игра | Кнопка «Новая игра» | Кнопка «Новая игра» |

## Уровни сложности

| Уровень | Поле | Мин |
| --- | --- | --- |
| Новичок | 9 × 9 | 10 |
| Любитель | 16 × 16 | 40 |
| Профи | 16 × 30 | 99 |

## Адаптивность

- Компьютер (от 1200 px): размер клеток подобран для 1280, 1366 и 1920 px.
- Планшет (768–1199 px): поле подстраивается под ширину экрана.
- Телефон (до 767 px): крупные клетки под палец, большое поле прокручивается в сторону.
